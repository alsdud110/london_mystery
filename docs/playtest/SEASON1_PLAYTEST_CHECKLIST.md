# London Mystery Season 1 — 8~12세 플레이 테스트 체크리스트

아이 한 명이 사건 하나를 플레이할 때 진행자(보호자·교사·팀원)가 한 부씩 씁니다.
정답은 Game Master의 **정답표(도우미용)** 에서 볼 수 있습니다. 아이에게는 보여 주지 마세요.

---

## 1. 준비

**테스트 빌드.** 일반 빌드에는 테스트 도구가 보이지 않습니다.

```
flutter build apk --dart-define=LM_PLAYTEST=true
```

(`flutter run` 디버그 실행에서는 따로 설정하지 않아도 보입니다.)

**원하는 사건부터 시작하기**
1. 시작 화면 가운데의 돋보기 인장을 **길게 누르기** → 곱셈 문제 풀기 → GAME MASTER
2. 아래 **플레이 테스트 도구**에서 `CASE NN부터` → `시작`
   - 이 기기의 진행 기록이 모두 지워집니다.
   - 앞 사건들은 "해결함"으로 표시됩니다. 힌트·배지 기록은 없고, Case Archive에는 앞 사건의 증거가 보입니다.
3. Case Files에 그 사건이 열리고 선택된 채로 나타납니다 → `BEGIN INVESTIGATION`

**다음 아이로 넘어갈 때**
- 같은 사건을 다시 하려면 `지금 사건(CASE NN) 처음부터`
- 처음부터 하려면 `다음 플레이어를 위해 기기 초기화`

**현장 준비물**
- Case 01만 QR 카드가 필요합니다(Buckingham Palace 미션). Game Master 화면의 QR을 인쇄하거나 다른 기기에 띄워 두세요.
- Case 02~12는 기기만 있으면 됩니다.

**주의: 앞 사건을 이어받는 사건.** 아래 사건은 앞 사건을 기억하거나 Case Archive를 찾아봐야 풀립니다.
`CASE NN부터`로 바로 시작한 아이라면 "기억이 안 나서"인지 "영어·논리가 어려워서"인지 구분해서 기록하세요.

| 사건 | 필요한 앞 사건 |
|---|---|
| Case 08 Final | Case 03의 Red Button |
| Case 11 Final | Case 01의 Old Letter |
| Case 12 Mission 2 | Case 04의 Word Card |
| Case 12 Mission 3 | Case 02(Big Ben) |

## 2. 기록 방법

- 체크 항목마다 **O**(그렇다) / **△**(도움 받고 됨) / **X**(아니다) 중 하나를 적고, 이유를 한 줄 남깁니다.
- 시간은 미션마다 퍼즐 화면이 열린 순간부터 정답까지 잽니다.
- 사건을 해결한 뒤 **VIEW MY DETECTIVE REPORT**(보호자 확인)를 열면 확인할 수 있는 것
  - 전체 플레이 시간, 정답률, 힌트 사용 수, 찾아본 단어 수
  - 미션별 힌트 사용 수
- **진행자가 도와준 순간은 반드시 적어 주세요.** 무엇을 물었고 무엇을 말해 줬는지가 가장 중요한 자료입니다.
- 힌트 강도 판단: 힌트 1은 **어디를 볼지**, 힌트 2는 **어떻게 생각할지**를 알려 주는 것이 목표입니다. 힌트를 읽자마자 정답을 그대로 입력한다면 "답을 직접 알려준다"로 체크하세요.

## 3. 공통 체크 항목 (모든 사건)

각 사건 페이지에서 아래 10개 항목을 체크합니다.

1. □ 목표를 이해할 수 있는가? (사건 소개 후 "지금 뭘 찾아야 해?"라고 물었을 때 대답할 수 있는가)
2. □ 영어 문장을 이해할 수 있는가? (단어 찾기를 몇 번 썼는지, 막힌 단어)
3. □ Hint 없이 적절한 시간 안에 진행 가능한가? (목표: 미션당 5분 이내. 가설이므로 실측으로 조정)
4. □ Hint가 충분한가? (힌트 2개를 보고도 막혔는가)
5. □ Hint가 답을 직접 알려주지는 않는가?
6. □ Evidence가 의미가 있는가? (얻은 증거를 뒤에서 Notebook으로 다시 찾아보는가)
7. □ 다음 행동을 자연스럽게 알 수 있는가? (미션이 끝난 뒤 어디를 눌러야 할지 묻는가)
8. □ Story가 이해되는가? (사건이 끝난 뒤 "누가, 왜?"를 설명할 수 있는가)
9. □ Mission이 재미있는가? (표정·몰입, "또 할래"라고 말하는가)
10. □ Final Case가 납득되는가? (결말에 "아하!" 반응이 있는가, "왜?"라고 묻는가)
