## 1. Executive Summary

**London Mystery**는 한국의 8~12세 어린이가 빅토리아 시대 런던을 배경으로 영어 단서를 읽고, 증거를 모으며, 추론을 통해 사건을 해결하는 탐정 어드벤처 게임이다. 핵심 루프는 **English → Evidence → Deduction → Action**이다.

**V2 목표:** 기존 Season 1 플레이 경험을 그대로 보존하면서 온라인 서비스로 확장한다. **회원가입 없이 게스트 탐정으로 바로 체험**할 수 있고, 보호자가 원할 때 부모 계정을 만들거나 로그인해 게스트 진행 기록을 **특정 자녀 탐정 프로필에 연결**한다. 부모 계정 하나에 여러 자녀 프로필을 두고, 프로필별 저장·지갑을 완전히 분리하며, 계정 프로필은 클라우드 백업·기기 간 복원을 지원한다.

## 6. 핵심 여정

**신규(게스트):** 앱 실행 → 언어/지역 선택 → 「게스트로 시작」 → 탐정 이름 → Season Cover → Opening 1~5 → Case 01 → 기기 내 게스트 프로필 저장.

**신규(부모 계정):** 앱 실행 → 언어/지역 → 「부모 계정 연결」 → 보호자 안내·동의 → 가입/로그인 → 자녀 프로필 생성 → Season Cover → Case 01 → 프로필별 로컬 저장 + 클라우드 동기화.

**게스트 → 계정 연결:** 보호자 영역(부모 인증) → 가입/로그인 → 「이 기기의 게스트 기록 연결」 → 대상 자녀 프로필 선택(새 프로필 또는 기존 프로필) → 기존 클라우드 기록이 있으면 비교·선택 → 보호자 확인 → 업로드·서버 확인 → 연결 완료. 게스트 원본은 기기에 보존.

**기존 사용자(업데이트 직후):** 앱 실행 → 레거시 세이브를 게스트 프로필로 자동 이전(원본 보존) → 기존과 같은 「Welcome back」/CONTINUE ADVENTURE.

**복귀(계정):** 앱 실행 → 부모 세션 확인 → 자녀 프로필 선택 → 로컬 상태로 즉시 복원 후 동기화.

**오프라인:** 게스트는 항상 오프라인 동작. 계정 프로필은 로컬 데이터로 플레이 → 재연결 후 멱등 동기화. 최초 가입·동의·연결은 온라인 필요.

## 7. 어린이 보호와 신뢰

- 게스트 데이터(탐정 이름 포함)는 기기 밖으로 전송하지 않는다.
- 보호자 동의 완료 전에는 계정 생성·클라우드 저장 등 개인정보 처리 기능을 활성화하지 않는다.
- 부모 계정과 아동 프로필 분리, 최소 수집(탐정 별명만), 접근 통제, 삭제·내보내기 정책 수립.
- Parent Gate(곱셈 퀴즈)는 보호자 신원 확인이나 법적 동의가 아니다.
- 계정 연결·프로필 추가/삭제·초기화 등 데이터에 영향을 주는 액션은 아이가 단독으로 실행할 수 없게 한다.
- 개인정보·광고·결제·국가별 연령 기준은 출시 전 공식 규정 및 법률 검토가 필요하며 본 문서는 준법 인증이 아님.

# London Mystery — 제품 요구사항 정의서 (PRD)

> 문서 기준일: 2026-10-13  
> 근거: 지금까지 공유된 London Mystery 개발 내역 및 Claude Code 실행 보고. 저장소 전체 소스를 이 문서 작성 과정에서 직접 검증한 것은 아니므로, 코드와 차이가 있으면 실제 구현을 확인해 갱신한다.  
> 상태 표기: **구현 보고** = 개발 및 테스트 통과가 보고됨 / **미검증** = 실제 기기 또는 어린이 사용자 검증 전 / **향후** = 미구현 계획.


## 1. 제품 개요

| 항목 | 내용 |
|---|---|
| 제품명 | London Mystery |
| 장르 | 어린이용 영어 기반 탐정 어드벤처 / 스토리 퍼즐 |
| 플랫폼 | Flutter 기반 모바일 앱 (실제 출시 OS·스토어 범위 최종 확인 필요) |
| 주요 대상 | 한국의 8~12세 어린이 및 보호자 |
| 핵심 경험 | **English → Evidence → Deduction → Action** |
| 플레이 구조 | Season → Case → Story → Map → Mission → Evidence/Notebook → Case Solved |
| Season 1 | 총 12 Cases, 50 Missions (일반 38, Final 12) |

| 운영 형태 | 현재 오프라인/로컬 진행 저장 중심; 광고·구독은 구현되지 않음 |

### 1.1 한 줄 소개
런던을 탐험하는 어린이 탐정이 영어 단서를 읽고 증거를 수집하며 추리로 미스터리를 해결하는 스토리형 어드벤처 게임.

### 1.2 해결하려는 문제
전통적인 영어 학습 앱은 단어 암기와 문제 정답에 초점을 맞추기 쉽다. London Mystery는 영어 문장을 읽어야 사건의 의미를 이해하고, 앞서 발견한 증거를 활용해 다음 행동을 결정하는 **목적 중심의 영어 사용 경험**을 지향한다.

## 2. 대상 사용자와 요구

| 사용자 | 니즈 | 제품 대응 |
|---|---|---|
| 8~9세 초·중급 학습자 | 짧은 문장, 분명한 피드백, 막히지 않는 도움 | 문맥형 오답 피드백, 2단계 Tip, 단어 뜻 조회 |
| 10~11세 중급 학습자 | 이야기에 몰입하면서 실제 추리 | 증거 수집, 장소 탐색, 사건 간 단서 연결 |
| 11~12세 중·상급 학습자 | 너무 유치하지 않은 난도와 서사 | 다단계 추론, 과거 Case의 증거 재사용, 시즌 결말 |
| 보호자 | 무엇을 경험했는지, 안전하게 즐기는지 확인 | Parent Report, Parent Gate, 과장 없는 활동 기반 기록 |

대치동 영어 사교육 환경에 익숙한 가정은 **초기 시장 가설**이며, 실제 영어 수준이나 구매 의사를 일률적으로 가정하지 않는다. 어린이 관찰 플레이테스트 전에는 학습 효과·시장 적합성을 입증했다고 표현하지 않는다.

## 3. 제품 원칙

1. **탐정 경험 우선**: 영어는 추리와 행동을 위한 도구다.
2. **증거의 실질적 역할**: 획득한 단서는 다음 선택에 실제로 쓰여야 한다.
3. **공정한 도움**: Coin 부족으로 추리 진행이 막히지 않아야 한다.
4. **연속성**: Case 간 인물·단서·표현이 이어진다.
5. **어린이 중심 UX**: 읽기 쉬운 문구, 명확한 버튼, 작은 화면 대응.
6. **부모 신뢰**: Parent Report는 관찰된 행동을 보여주며 실력을 단정하지 않는다.
7. **세이브 호환**: 기존 사용자 진행과 역사적 XP를 보존한다.

## 4. 핵심 게임 경험

### 4.1 시작과 탐정 정체성
신규 사용자는 Season Cover, 오프닝 5장면, 사건 수락, Case 01 사건 파일을 통해 시즌에 진입한다. 기존 사용자는 타이틀에서 진행을 이어갈 수 있다. 탐정 이름/정체성, Season Investigation Board, Case Files가 탐험의 맥락을 제공한다.

### 4.2 반복 플레이 루프
**Story Intro → Map → Mission(탐색·편지/단서·퍼즐) → Well Done → Story Scene → Map**을 반복하고, Case의 마지막에는 **Final Mission → Case Solved → Investigation Board**로 연결된다. 정확한 화면별 라우팅은 코드 기준 최종 확인 필요.

### 4.3 학습·추리 방식
- 영어 지문·편지·증언을 읽고 단서 의미를 파악한다.
- 지도와 증거, Notebook/Archive를 통해 정보를 다시 확인한다.
- 정답만 맞히는 활동보다 **읽은 정보로 추론하는 활동**을 지향한다.
- 시즌 50개 미션에 학습 메타데이터가 있으며, 과거 설계 분류에서 English Essential 41/50으로 보고되었다. 이는 **설계 분류**이지 실제 학습 성과가 아니다.
